# 帳篷 × 營位 3D 搭設模擬

左邊選帳篷、右邊選營位，中間用 3D 看實際搭起來放不放得下。

- 內建 9 款帳篷（長寬高為原廠公布尺寸），另可自訂尺寸、外型與顏色
- 帳篷型式含車邊帳（高的開口側靠車，可把車拖過來貼齊）、金字塔帳、充氣帳、單人登山帳
- 從帳型介紹頁按按鈕過來（index.html#type-帳型），會自動帶入該帳型
- 可再加第 2 頂帳篷（含獨立的自訂尺寸），各自拖曳旋轉，並檢查兩頂是否重疊
- 天幕：3 款品牌六角天幕與 3 種方形規格，可自訂尺寸與顏色，可和帳篷一起擺放
- 營位：草地、碎石、木棧板、雨棚，可自訂長寬
- 包區包場模式：自訂整區大小，帳篷最多 10 頂、天幕 3 張、車 10 輛，每頂帳篷可配 2 人、2 椅、1 桌、1 寵物、1 燈；帳篷重疊會標紅；配置自動存在瀏覽器，可複製分享連結把配置傳給別人
- 存圖：把目前的 3D 畫面連同判定結果存成一張圖片
- 營區環境：草地、森林、河邊、海邊、高山；天氣／時段：晴天、多雲、雨天、起霧、黃昏、夜晚
- 桌椅與燈：兩張克米特椅型折疊椅、四腳方桌、汽化燈（夜晚與黃昏會發光），可選尺寸與顏色
- 營繩與營釘範圍檢查、可選性別與身高的人物、可選車型的車輛、可選花色體型的貓狗，都能拖曳擺放

另有「帳型 3D 介紹」頁（types.html）：十一種帳型的概念造型、六項評分與優缺點。

3D 外型為依結構類型製作的通用造型，非各型號的複刻。資訊僅供參考，請依官方資訊為準。
